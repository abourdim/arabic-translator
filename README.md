# 🌐 تطبيق المترجم العربي (يعمل داخل المتصفح)

تطبيق **مترجم عربي حديث وخفيف** يعمل **كليًا داخل المتصفح** بدون أي خادم (Backend)، بدون أطر عمل، وبدون مفاتيح API.

يدعم التطبيق:
- 🔁 **الترجمة في الاتجاهين** (العربية ⇄ الإنجليزية / الفرنسية)
- 🎙️ **الاستماع (تحويل الكلام إلى نص)**
- 📋 **نسخ النص إلى الحافظة**
- 💾 **حفظ آخر نص ولغات تلقائيًا**
- 🧹 **زر مسح عام في بطاقة مستقلة**

---

## ✨ المميزات

### 🔁 الترجمة في الاتجاهين
- ترجمة من اليسار إلى اليمين أو العكس
- اللغات المدعومة:
  - العربية (AR)
  - الإنجليزية (EN)
  - الفرنسية (FR)

### 🎙️ الاستماع (تحويل الكلام إلى نص)
- إملاء صوتي مباشر في مربع النص الأيسر
- يعتمد على **Web Speech API**
- أفضل دعم في **Chrome / Edge**
- اللغة الافتراضية للتعرّف العربي: **ar-DZ**

### 📋 النسخ إلى الحافظة
- نسخ النص من أي جهة
- يستخدم:
  - Clipboard API عند السماح
  - طريقة بديلة تلقائية عند الحظر

### 💾 الحفظ التلقائي
يقوم التطبيق تلقائيًا بحفظ:
- آخر نص في الجهة اليسرى
- آخر نص في الجهة اليمنى
- لغة المصدر
- لغة الهدف

ويتم استرجاعها تلقائيًا عند فتح الصفحة مرة أخرى.

### 🧹 زر المسح (إجراء عام)
- يمسح النصين معًا
- موجود في بطاقة مستقلة لأنه إجراء مشترك

---

## 🧠 كيف يعمل التطبيق

### الترجمة
- يستخدم واجهة Google Translate العامة (غير رسمية):
```
https://translate.googleapis.com/translate_a/single
```
- لا يتطلب مفتاح API
- يحتاج اتصالًا بالإنترنت

### التعرّف على الكلام
- يعتمد على:
```js
window.SpeechRecognition || window.webkitSpeechRecognition
```

### حفظ البيانات
- باستخدام:
```js
localStorage
```
- لا يتم إرسال أي بيانات خارج جهازك

## 🚀 طريقة التشغيل

### ✅ الطريقة المفضلة (موصى بها)

تشغيل خادم محلي:
```bash
python -m http.server
```

ثم فتح:
```
http://localhost:8000
```

### ⚠️ التشغيل عبر file://
- الترجمة قد تعمل
- الميكروفون والنسخ قد يكونان محجوبين
- يفضّل استخدام localhost أو https

# 🌐 Arabic Translator App (Browser-Only)

A **lightweight, modern Arabic translator** that runs **entirely in the browser** — no backend, no frameworks, no API keys.

## Features
- 🔁 Bidirectional translation (Arabic ⇄ English / French)
- 🎙️ Speech-to-text (Listen)
- 📋 Copy to clipboard
- 💾 Auto-save last text & languages
- 🧹 Global clear button

## Technologies
- Google Translate public endpoint (unofficial)
- Web Speech API
- localStorage

## Privacy
All data stays on your device. No tracking, no backend.
